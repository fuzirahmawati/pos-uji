# POS Uji

Project ini dibuat menggunakan Laravel 13 sebagai bagian dari tugas PKL Astacode.

## Struktur Folder Laravel

### app/
Berisi logika utama aplikasi seperti Model, Controller, Middleware, dan komponen inti lainnya.

### app/Models/
Berisi Model yang digunakan untuk berinteraksi dengan database.

### app/Http/Controllers/
Berisi Controller yang menerima request dari pengguna, mengolah data, lalu mengembalikan response.

### bootstrap/
Berisi proses bootstrapping aplikasi Laravel.

### config/
Berisi file konfigurasi aplikasi.

### database/
Berisi migration, seeder, dan factory database.

### public/
Berisi file yang dapat diakses langsung melalui browser, seperti `index.php`, CSS, JavaScript, dan gambar.

### resources/
Berisi Blade Template, CSS, JavaScript, dan aset frontend.

### routes/
Berisi file routing aplikasi seperti `web.php` dan `console.php`.

### storage/
Berisi file log, cache, session, dan file hasil upload.

### tests/
Berisi file pengujian aplikasi.

### vendor/
Berisi package Laravel dan dependency yang diinstal menggunakan Composer.
